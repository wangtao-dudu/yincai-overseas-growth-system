# 完整功能与验收说明

## 第一期：正式获客核心

| 功能 | 已实现能力 | 验收方法 |
|---|---|---|
| 海外网站 | 首页、产品库、详情页、询价、隐私、站点地图 | 发布产品后可以公开访问并提交询价 |
| 产品素材后台 | 图片、视频、参数、工艺、检测和发布状态 | 新建产品并勾选发布 |
| 客户管理 | 企业去重、多联系人、来源、分级、沟通记录 | 询价自动建立客户，表格可批量导入 |
| 询价和样品 | 询价建档、样品审批、费用、物流、签收和反馈 | 公开询价后后台出现商机与任务 |
| 销售跟进 | 十阶段漏斗、负责人、截止时间、自动任务 | 报价后自动产生第2、7、14、30天任务 |
| 经营看板 | 客户、询价、样品、商机、订单、回款和来源 | 管理员首页实时汇总 |
| 权限备份 | 八类岗位、接口拦截、操作日志、完整备份下载 | 销售无法访问用户与备份模块 |

## 第二期：交易和交付

| 功能 | 已实现能力 |
|---|---|
| 三档报价 | 每个产品设置三档数量和价格，叠加工艺、包装、模具、运费 |
| 样品寄送 | 审批、样品费、运费、物流商、运单、签收和客户反馈 |
| 订单回款 | 订单金额、毛利、交付状态、分次回款和付款状态 |
| 客诉质量 | 问题等级、根因、纠正措施、预防措施、负责人和关闭状态 |
| 环保数据卡 | 再生材料比例、重量、材料组成、回收、替换设计、文件和核验状态 |
| 多语言 | 四种语言草稿、人工修改、审核批准和公开页面 |
| 渠道商 | 区域、客户资源、产品范围、目标、折扣、独家条件和协议期限 |

## 第三期：智能效率

所有智能结果均为可解释规则，不使用无法审计的黑箱结论。

| 功能 | 计算依据 |
|---|---|
| 客户评分 | 市场、企业类型、网站、联系人职位、采购能力、商机成熟度和风险 |
| 产品推荐 | 产品类别、容量、材料、采购量和起订要求 |
| 包装选择器 | 客户输入需求，输出匹配度、理由及产品页面 |
| 成本估算 | 三档价格、工艺、包装和模具配置，输出规划区间 |
| 产品介绍 | 产品结构化参数生成英文草稿，人工确认后发布 |
| 翻译审核 | 翻译服务生成草稿，后台人工批准后才公开 |
| 风险预警 | 商机停滞、跟进逾期、报价超时和样品无反馈 |
| 经营预测 | 预计成交时间、商机金额和阶段概率计算三十天与九十天预测 |

## 权限范围

- 管理员：全部模块、用户、备份和操作日志；
- 海外负责人：业务、产品、质量、渠道商、多语言和智能分析；
- 销售：获客、客户、商机、询价、交易和智能分析；
- 产品技术：产品、报价环保规则、多语言和推荐分析；
- 质量：质量、环保资料、样品和订单；
- 内容运营：产品内容、多语言和获客入口；
- 财务：订单、回款和经营预测；
- 交付：样品、订单和质量记录。

## 不能伪造的外部条件

- 广告平台、领英、邮箱和即时通信授权密钥；
- 银彩真实产品图片、视频、价格、起订量、检测和环保数据；
- 正式域名、安全证书和邮件发送账户；
- 翻译服务授权以及合格人工审核人。

这些资料不包含在程序代码中，必须由银彩部署时提供。
