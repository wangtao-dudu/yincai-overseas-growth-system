# 银彩海外全渠道增长系统

这是一套可以自行部署到服务器的银彩海外全渠道增长系统完整版本，包含对外海外网站和中文管理后台。第一、第二、第三期功能共享同一套产品、客户、商机、交易和权限数据。

## 当前版本

V4 改版分支采用独立语言网址（如 `/en/products`、`/de/products`），统一产品页视觉，并加入可解释选型、透明成本拆分、询价附件、隐私同意记录和内容草稿—预览—发布—回滚流程。

## 已实现功能

- 对外英文首页、产品中心、产品详情和询价页面；
- 后台上传产品图片、视频和参数，审核后发布到网站；
- 网站询价自动创建企业、联系人、商机和跟进任务；
- 企业档案、多个联系人、沟通记录与客户分级；
- 十阶段商机漏斗和自动成交概率；
- 样品、报价、订单、回款和毛利记录；
- 今日任务、渠道来源、加权商机金额和经营看板；
- 谷歌、领英、邮件、社交、展会、渠道商、即时通信等来源标记；
- 外部平台线索接入接口；
- 中英文表头目标客户批量导入；
- 登录保护、表单防伪、防危险文件名、上传格式及大小限制；
- 岗位权限、操作审计、询价频率限制和垃圾表单陷阱；
- 三档自动报价、报价审批状态和报价后四次自动跟进；
- 样品审批、费用、物流、签收及反馈管理；
- 回款流水、客诉质量闭环和渠道商管理；
- 产品结构化环保数据卡和人工核验状态；
- 德语、法语、西班牙语和阿拉伯语翻译草稿及人工审核发布；
- 客户智能评分、产品智能推荐和商机风险预警；
- 包装选择器、成本估算和产品介绍自动生成；
- 三十天、九十天及全部有效商机经营预测；
- 搜索站点地图、访问统计配置、活动参数追踪和隐私页面；
- 容器化部署、数据持久化和备份脚本。

## 推荐服务器

- 两个处理器核心；
- 四吉字节内存；
- 四十吉字节固态硬盘；
- 六十四位常见发行版服务器系统；
- 已安装容器引擎和容器编排组件；
- 域名已经解析到服务器公网地址。

早期访问量不大时，一个核心和两吉字节内存也可以运行，但不建议同时在同一服务器运行大量其他程序。

## 部署步骤

### 1. 上传并解压

将整个目录上传到服务器，例如：

```bash
unzip 银彩海外全渠道增长系统.zip
cd yincai_growth_system
```

### 2. 创建正式环境配置

```bash
cp .env.example .env
```

编辑 `.env`，至少修改以下内容：

- `SECRET_KEY`：至少三十二位随机字符；
- `ADMIN_PASSWORD`：管理后台强密码；
- `API_TOKEN`：外部平台接入密钥；
- `COMPANY_NAME`：海外公司或品牌名称；
- `PUBLIC_EMAIL`：海外业务邮箱；
- `PUBLIC_PHONE`：海外业务电话或即时通信号码。
- `ANALYTICS_ID`：网站访问统计编号；
- 邮件通知配置：用于新询价到达后通知销售；
- 翻译服务配置：用于自动生成多语言草稿。

可以使用下面的命令生成随机密钥：

```bash
python3 -c "import secrets; print(secrets.token_urlsafe(48))"
```

不要把正式 `.env` 文件发送给第三方，也不要上传到公开代码仓库。

### 3. 启动系统

```bash
docker compose up -d --build
```

访问地址：

- 海外网站：`http://服务器地址:8000/`
- 管理后台：`http://服务器地址:8000/admin/login`
- 健康检查：`http://服务器地址:8000/api/v1/health`

### 4. 配置域名

把 `nginx/yincai.conf` 复制到服务器网站配置目录，将其中域名替换为真实域名，再配置免费安全证书。若使用宝塔面板，可新建一个反向代理网站，把目标地址填写为：

```text
http://127.0.0.1:8000
```

上传大小设置为一百兆，并开启强制安全访问。

## 首次使用顺序

1. 登录管理后台；
2. 在“产品与素材”创建二十个主推产品；
3. 上传产品主图、视频、参数、工艺、检测和环保数据；
4. 勾选“发布到海外网站”；
5. 在“企业与联系人”导入或者创建第一批目标客户；
6. 在“商机漏斗”推进客户；
7. 在“样品·报价·订单”记录交易过程；
8. 每天从“经营总览”的待办任务开始工作。

## 外部平台线索接入

系统预留统一线索接口，便于后续连接邮件工具、展会扫码、自动化平台和其他获客平台。

请求地址：

```text
POST /api/v1/leads
```

请求头：

```text
Authorization: Bearer 你的接入密钥
Content-Type: application/json
```

数据示例：

```json
{
  "company_name": "示例品牌",
  "contact_name": "采购联系人",
  "email": "buyer@example.com",
  "phone": "+1 000 000 0000",
  "title": "采购负责人",
  "country": "美国",
  "company_type": "美容品牌",
  "source": "领英开发"
}
```

接口成功后会自动创建企业、联系人和两小时内处理的跟进任务。后续可以继续扩展平台回调、邮件解析和线索去重。

## 数据备份

手动执行：

```bash
sh scripts/backup.sh
```

备份包括数据库和上传资料，默认保留三十天。正式运行时应在服务器计划任务中每天执行一次，并将备份复制到另一台设备或者对象存储，不能只保存在原服务器。

管理员也可以在后台“安全与数据备份”中创建并下载即时完整备份。

## 更新程序

更新代码后执行：

```bash
docker compose up -d --build
```

更新前先运行备份脚本。不要直接删除 `data` 和 `uploads` 目录，这两个目录分别保存业务数据库和产品素材。

## 数据与密钥安全

运行时数据库不会提交到代码仓库，新环境会在 `data/yincai.db` 自动建立。正式环境若缺少至少 32 位的 `SECRET_KEY`，或仍使用默认/过短管理密码，程序会拒绝启动。历史提交中若曾包含真实数据库，需要另行执行仓库历史清理并轮换其中可能出现的个人信息或凭据。

询价附件仅允许 PNG、JPG、WEBP、PDF，并同时验证扩展名、文件签名和 15 MB 上限。可选访问统计在访客明确同意前不会加载。

## 上线前安全清单

- 修改默认管理密码和全部密钥；
- 只开放八十和四百四十三端口，八千端口仅供本机反向代理访问；
- 正式域名开启安全证书和强制安全访问；
- 配置服务器防火墙、自动安全更新和登录保护；
- 每日备份并定期测试恢复；
- 所有账号归公司，不使用员工私人账号作为唯一管理员；
- 环保、认证、价格和交期信息必须经过人工审核；
- 正式大规模使用前，将数据库迁移到独立数据库服务并接入对象存储。

## 外部平台边界

系统自身已经完成来源追踪、活动参数、表格导入、统一线索接口和完整销售闭环。领英、谷歌广告、社交平台、邮箱和即时通信的账号数据属于各平台控制范围，银彩仍需使用自己的企业账户申请授权并把密钥填入服务器配置。获得授权后可以直接连接现有接口，不需要推翻系统。

自动翻译同样需要配置银彩选择的翻译服务。未配置时，系统仍会建立待人工翻译任务，但不会假装已经完成准确翻译。

完整功能、验收路径和岗位权限说明参见 `FEATURES.md`。
